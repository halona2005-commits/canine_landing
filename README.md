
# 🐾 CanineID — Every Dog. One Unique Identity.

CanineID is a coming-soon landing page for a canine biometric identification project that explores a smarter way to recognize and identify dogs using their unique nose-print patterns.

Our vision is to give every dog a recognizable identity and help build a future where technology supports pet identification.

## ✨ Features

- **Elegant Landing Page:** A warm cream aesthetic with sophisticated typography and a minimal layout.
- **Nose-Print Biometric Focus:** Highlights the dog's nose as the primary biometric feature.
- **Facial Scan Visuals:** Includes facial landmark indicators and a biometric scan overlay.
- **Subtle Animations:** Animated scanning lines, pulsing nose indicators, and smooth entrance effects.
- **Responsive Design:** Adapts to desktop, tablet, and mobile screens.
- **Social Media Links:** Provides links for visitors to follow the project's journey.
- **Coming Soon Message:** Introduces the project ahead of its launch.

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Google Fonts — Playfair Display and DM Sans

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

### 2. Open the project folder

```bash
cd CanineID
```

### 3. Run the landing page

Open `index.html` directly in your web browser.

Alternatively, open the folder in Visual Studio Code and use the Live Server extension.

No build tools or package installation are required.

## 🖼️ Image Configuration

The landing page uses `dog-hero.png` for its main biometric visual.

Ensure the image is located in the same directory as `index.html`.

If you use a different image filename, update the image path in `index.html` accordingly.

## 🎨 Design Philosophy

CanineID combines warm neutral colors, elegant typography, and subtle biometric-inspired visuals to create a premium, welcoming introduction to canine identity technology.

The design emphasizes the dog's nose as the central visual feature while keeping the overall experience clean and accessible.
